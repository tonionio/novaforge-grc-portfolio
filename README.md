# NovaForge GRC & Security Program Portfolio

A hands-on Governance, Risk & Compliance (GRC) portfolio demonstrating how an enterprise security governance program can be designed, documented, and matured from the ground up.

This project uses **NovaForge**, a fictional robotics and advanced manufacturing company, as the business environment for practical GRC work.

## Project Objective

The goal of this portfolio is to demonstrate practical, job-relevant GRC skills by developing the artifacts, governance structures, risk processes, controls, policies, evidence, and reporting that a GRC analyst may support in a real organization.

The program is designed around concepts from:

- NIST Cybersecurity Framework (CSF)
- ISO/IEC 27001
- Enterprise risk management
- Security governance
- Third-party risk management
- Audit evidence and compliance reporting

## Completed Foundation

### NF-GRC-001 — GRC Program Charter
Defines the purpose, objectives, scope, stakeholders, governance responsibilities, planned deliverables, risks, and success criteria for the NovaForge GRC program.

### NF-GRC-002 — Company Profile
Establishes the organizational, operational, technical, and business context needed to perform meaningful risk assessments and select appropriate security controls.

### NF-GRC-003 — Organizational Chart & Governance Structure
Defines executive, IT, security, engineering, operations, finance, HR, legal, sales, and supporting business functions, including GRC and security responsibilities.
