## Purpose

The Program Charter formally establishes the NovaForge Manufacturing Governance, Risk & Compliance (GRC) Program. It authorizes development of a structured governance framework for managing cybersecurity risk while supporting business objectives.

The charter establishes the program's purpose to:

- Establish information security governance.
- Identify and assess organizational risks.
- Develop security policies and standards.
- Improve security maturity.
- Support regulatory and contractual compliance.
- Provide executive visibility into cybersecurity risk.

## Program Objectives

The charter defines the following target outcomes:

- Established governance framework.
- Documented asset inventory.
- Comprehensive risk assessment.
- Centralized risk register.
- Information security policies.
- Vendor risk management procedures.
- Incident response documentation.
- Executive security reporting dashboards.
- Security metrics and KPIs.
- Control mapping aligned to NIST CSF 2.0.

## Scope

### Included

Corporate offices, manufacturing facilities, cloud services, end-user devices, servers, network infrastructure, business applications, third-party vendors, security documentation, and risk management processes.

### Excluded

Physical implementation of security technologies, penetration testing, live production systems, software development, and Security Operations Center (SOC) monitoring.
